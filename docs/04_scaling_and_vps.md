# 🚀 Масштабирование и распределенная выкачка (VPS)

## Сборка автономного бинарника
Для запуска на удаленных Linux-серверах (Ubuntu/Debian) не требуется установка Rust:
```bash
cargo build --release
# Готовый файл: target/release/stac_service (~15-20 МБ)
```

## Архитектура распределенного сбора данных
Для обхода географических задержек и троттлинга облаков (Azure/AWS) оптимальна схема **Hub-and-Spoke**:
1. **Центральный Storage-сервер** (Европа, RAID-5/JBOD на 40+ ТБ): держит `MinIO` и `pgSTAC`.
2. **3–4 легких VPS-воркера** (Нидерланды/Германия, 1 Гбит/с): запускают бинарник `stac_service` с разными `config.toml` (разделение по коллекциям, квадратам BBOX или сезонам) и стримят файлы напрямую в центральный MinIO.

## Слияние бакетов (если качали на независимые Storage VPS)
Для объединения данных с нескольких серверов в единое хранилище используйте официальный клиент `mc` (MinIO Client):
```bash
mc alias set vps1 http://IP_VPS_1:9000 minioadmin minioadmin
mc alias set main http://IP_MAIN:9000 minioadmin minioadmin

# Зеркалирование с проверкой контрольных сумм без перезаписи существующих файлов
mc mirror vps1/geo-data main/geo-data
```
